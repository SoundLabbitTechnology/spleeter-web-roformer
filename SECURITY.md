# Security Policy

## Supported versions

Security fixes for this fork are applied on a best-effort basis to the
`master` branch of
[SoundLabbitTechnology/spleeter-web-roformer](https://github.com/SoundLabbitTechnology/spleeter-web-roformer).

For vulnerabilities that also affect upstream
[JeffreyCA/spleeter-web](https://github.com/JeffreyCA/spleeter-web), please
consider reporting them to the upstream project as well.

## Reporting a vulnerability

**Do not open a public GitHub Issue for security vulnerabilities.**

Please report security issues privately using one of the following:

1. **Preferred:** [GitHub Private Vulnerability Reporting](https://github.com/SoundLabbitTechnology/spleeter-web-roformer/security/advisories/new)
2. **Email:** [info@soundlabbittechnology.co.jp](mailto:info@soundlabbittechnology.co.jp)
   with a subject line such as `[SECURITY] spleeter-web-roformer`

Include as much detail as you can:

- Affected version / commit
- Steps to reproduce
- Impact assessment
- Any known workarounds

We will acknowledge receipt when possible and coordinate disclosure after a fix
is available or a mitigation path is clear.
